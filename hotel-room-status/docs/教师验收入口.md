# 教师验收入口

在线网址：https://cst-poker-threaded-applications.trycloudflare.com

打开网址直接进入免登录访客演示，可查看公开房态样例、规则依据、知识图谱和流程说明。

## 完整功能验收

点击右上角“工作人员登录”。账号密码随《教师验收材料_含演示账号.zip》单独交给老师，不写入公开仓库。材料同时包含Issue与PR的Word报告及课堂提交清单。

1. 前台账号front_a：核对101房，检查来源、风险原因和真实模型状态，选择house_a，人工确认交接。
2. 客房账号house_a：进入交接任务，确认接手；管理员不能替指定接手人确认。
3. 管理员账号admin_a：查看账号管理、知识维护、操作审计、Wiki生成及审核发布。
4. 前台账号front_b：查看另一酒店资料及基础版配额，验证租户分层。
5. 知识问答可输入“房间已清扫但还未查房，应该如何交接？”，展开引用依据。模型不可用或输出未通过校验时明确显示规则降级。
